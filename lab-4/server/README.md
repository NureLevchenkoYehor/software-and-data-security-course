# Серверна частина

## Передумови

- Встановлений Python 3.11 або новіший.
- Доступ до мережі для встановлення Python-пакетів.
- Порт `8000` має бути вільним.

## Попередня установка

1. Перейдіть до каталогу сервера:

   ```sh
   cd server
   ```

2. Створіть і активуйте віртуальне середовище:

   ```sh
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Встановіть серверний пакет із залежностями (якщо немає):

   ```sh
   python -m pip install --upgrade pip
   python -m pip install .
   ```

4. Згенеруйте пару RSA-2048 ключів:

   ```sh
   python bin/generate_keys.py
   ```

   Команда створює два PEM-файли в каталозі `server/`:

   - `private_key.pem` — закритий ключ сервера для підпису рукостискання;
   - `public_key.pem` — відкритий ключ сервера.

   Команда зупиняється з помилкою, якщо хоча б один із цих файлів уже існує. Для нової пари спочатку видаліть обидва старі ключі вручну.

5. Передайте новий відкритий ключ клієнту:

   ```sh
   cp public_key.pem ../client/src/secrets/public_key.pem
   ```

   Повторюйте цей крок після кожної перегенерації ключів. Сервер завантажує приватний ключ під час запуску; приватний ключ не передається клієнту і не має потрапляти в систему контролю версій.

## Запуск

Після активації `.venv` запустіть сервер з каталогу `server/`:

```sh
fastapi dev bin/main.py
```

Сервер буде доступний за адресою `http://localhost:8000`.
