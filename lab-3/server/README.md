# Серверна частина

## Передумови

- Встановлений Python 3.11 або новіший.
- Доступ до мережі для встановлення Python-пакетів.
- Порт `8000` має бути вільним.

## Попередня установка

1. Перейдіть до каталогу сервера:

   ```sh
   cd server
   ```

2. Створіть і активуйте віртуальне середовище:

   ```sh
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Встановіть серверний пакет із залежностями (якщо немає):

   ```sh
   python -m pip install --upgrade pip
   python -m pip install .
   ```

4. Згенеруйте пару RSA-2048 ключів:

   ```sh
   python bin/generate_keys.py
   ```

   Команда створює два PEM-файли в каталозі `server/`:

   - `private_key.pem` — закритий ключ для підпису дайджестів;
   - `public_key.pem` — відкритий ключ для перевірки підпису.

   Команда зупиняється з помилкою, якщо хоча б один із цих файлів уже існує. Для 
   нової пари спочатку видаліть обидва старі ключі вручну. Ключі не мають потрапляти 
   в систему контролю версій.

## Консольна утиліта

Після активації `.venv` утиліту запускають з каталогу `server/`:

```sh
python bin/cli.py hash ../samples/original/*         # дайджести файлів
python bin/cli.py avalanche                          # лавинний тест
python bin/cli.py samples                            # генерація документів і пошук колізій
python bin/cli.py collide ORIGINAL MODIFIED -o OUT   # колізія для довільної пари файлів
python bin/cli.py sign FILE -o sig.txt               # підпис дайджесту
python bin/cli.py verify FILE sig.txt                # перевірка підпису
```

Довжина дайджесту задається параметром `-b` (2, 4 або 8, за замовчуванням 8). 
Довідка щодо кожної команди: `python bin/cli.py КОМАНДА -h`.

## Запуск сервера

Після активації `.venv` запустіть сервер з каталогу `server/`:

```sh
fastapi dev bin/main.py
```

Сервер буде доступний за адресою `http://localhost:8000`.
