# Клієнтська частина

## Передумови

- Встановлений Bun 1.3 або новішої версії.
- Запущений сервер, відповідно до інструкцій із файлу `server/README.md`.

## Попередня установка

1. Перейдіть до каталогу клієнта:

   ```sh
   cd client
   ```

2. Встановіть залежності:

   ```sh
   bun install
   ```

## Запуск

Запустіть сервер згідно з `../server/README.md`, потім у каталозі `client` виконайте:

```sh
bun dev
```

Відкрийте [http://localhost:3000](http://localhost:3000). Вкладка **Digest** 
обчислює та порівнює дайджести файлів, вкладка **RSA signature** підписує дайджест 
файла та перевіряє підпис. Для перевірки можна використати документи з каталогу 
`../samples/`.
