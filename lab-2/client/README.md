# Клієнтська частина

## Передумови

- Встановлений Bun 1.3 або новішої версії.
- Запущений сервер, відповідно до інструкцій із файлу `server/README.md`.
- Відкритий RSA-ключ сервера у `src/secrets/public_key.pem`.

## Попередня установка

1. Перейдіть до каталогу клієнта:

   ```sh
   cd client
   ```

2. Встановіть залежності:

   ```sh
   bun install
   ```

3. Отримайте `public_key.pem`, згенерований сервером за інструкцією в `../server/README.md`.
4. Скопіюйте вміст цього файла до `src/secrets/public_key.pem` у клієнті:

   ```sh
   cp ../server/public_key.pem src/secrets/public_key.pem
   ```

   Файл у клієнта має містити лише PEM-публічного ключа у форматі:

   ```text
   -----BEGIN PUBLIC KEY-----
   ...
   -----END PUBLIC KEY-----
   ```

   Якщо серверні ключі було перегенеровано, повторно скопіюйте новий відкритий ключ. Інакше перевірка підпису рукостискання завершиться помилкою.

## Запуск

Запустіть сервер згідно з `../server/README.md`, потім у каталозі `client` виконайте:

```sh
bun dev
```

Відкрийте [http://localhost:3000](http://localhost:3000). Клієнт автоматично починає протокол рукостискання; тестові дані для входу — `rimworld` / `awolnation`.
